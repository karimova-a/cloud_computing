# Deployment Guide: KazRE Listing Enricher

This guide contains all instructions required to deploy your Bot and Dashboard.

## 1. Local Testing
To test the environment natively on your machine:
```bash
# 1. Navigate to the directory
cd /Users/apple/Desktop/cloud/sis

# 2. Add API key
export GEMINI_API_KEY="your_api_key_here"

# 3. Make the start script executable
chmod +x start.sh

# 4. Start the application
./start.sh
```

## 2. Deploying to Railway.app (Free Tier)
Railway is ideal because it reads `Dockerfile` and `Procfile` natively.
1. Create a GitHub repository and push this `/sis` folder to it.
2. Go to [Railway.app](https://railway.app), login, and click **New Project** -> **Deploy from GitHub repo**.
3. Select your repository. Railway will automatically detect the `Procfile` and `Dockerfile`.
4. Go to the project **Variables** tab in Railway and add:
   - `GEMINI_API_KEY` = `your_value`
5. Go to the **Settings** tab -> **Generate Domain** so your dashboard is accessible via a public URL.

## 3. Deploying to Render.com (Free Tier)
Render offers a great Free Tier for web services.
1. Push this folder to GitHub.
2. Sign in to [Render.com](https://render.com) and click **New +** -> **Web Service**.
3. Connect your GitHub repository.
4. Render Configuration:
   - **Environment**: Docker
   - **Build Command**: (Leave default, Render uses Dockerfile)
   - **Start Command**: `./start.sh`
5. Click **Advanced** and add Environment Variable:
   - `GEMINI_API_KEY` = `your_value`
6. Click **Create Web Service**. Wait 3-5 minutes for the build to finish.

## 4. Keeping it Alive 24/7 (UptimeRobot)
Free tiers on Railway/Render often "spin down" or sleep after 15 minutes of inactivity. To prevent this:
1. Copy the public URL generated by Railway/Render (e.g., `https://kazre-app.onrender.com`).
2. Go to [UptimeRobot.com](https://uptimerobot.com) and create a free account.
3. Click **Add New Monitor**.
4. Monitor Type: `HTTP(s)`
5. Friendly Name: `KazRE Keep-Alive`
6. URL: Paste your Railway/Render URL.
7. Monitoring Interval: `5 minutes`.
8. Click **Create Monitor**. The bot will ping your site every 5 mins, preventing to go to sleep.
